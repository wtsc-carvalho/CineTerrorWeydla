# 🎬 CineTerror Weydla - Projeto Final (Módulo 3)

Aplicativo Android nativo desenvolvido em **Kotlin** com **Jetpack Compose**, integrando consumo de API REST via **Retrofit** e persistência local com **Room Database**, seguindo as diretrizes de **Interação Humano-Computador (IHC)**.

## ✅ Checklist de Requisitos Cumpridos (Módulo 3)
1. **Prática 01 e 02 (Kotlin + Jetpack Compose):** Interface 100% declarativa em Material Design 3.
2. **Prática 03 (Compose + Navigation):** Navegação estruturada entre *Catálogo API*, *Favoritos (Room)*, *Detalhes* e *Sobre*.
3. **Prática 04 e 06 (MVVM + StateFlow + Coroutines):** Gerenciamento de estado reativo e chamadas assíncronas seguras com `viewModelScope`.
4. **Prática 05 (Listas com LazyColumn):** Listagem performática de filmes com imagens via Coil.
5. **Prática 07 (Room - Persistência Local):** Banco de dados SQLite local (`cineterror_weydla_db`) permitindo favoritar filmes, cadastrar novos títulos, marcar como "Assistido" e salvar anotações pessoais.
6. **Prática 08 (Retrofit - Consumo de API):** Integração com a API pública *TVMaze* (`https://api.tvmaze.com/search/shows?q=horror`) com fallback offline integrado.
7. **Personalização e Publicação:** Nome próprio (`CineTerror Weydla`), ícone vetorial exclusivo (`ic_cineterror_logo.xml`), paleta de cores escura personalizada e permissão `INTERNET` configurada no `AndroidManifest.xml`.
